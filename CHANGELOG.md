# Changelog

Release notes for every published Furiko build. Each entry matches a [GitHub Release](https://github.com/furikoapp/furiko-releases/releases).

## [0.0.2](https://github.com/furikoapp/furiko-releases/releases/tag/v0.0.2) — 2026-10-10

### Changed

- The download helper can now load in the notarized build, so link imports can work
- One notice before your first import, for files and links alike
- Privacy settings list every connection Furiko makes
- Turn off yt-dlp update checks; a newer bundled yt-dlp is used when it wins
- Help menu: Send Feedback and Copy Diagnostics
- Cover marks now carry a note to remove only marks you have the right to remove
