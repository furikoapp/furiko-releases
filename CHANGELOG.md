# Changelog

Release notes for every published Furiko build. Each entry matches a [GitHub Release](https://github.com/furikoapp/furiko-releases/releases).

## [0.0.1](https://github.com/furikoapp/furiko-releases/releases/tag/v0.0.1) — 2026-10-10

### Added

- Import a video file or a link
- Trim and crop on a filmstrip
- Export for wallpaper engines and Instagram, including 16:9 and 9:16 from one trim
- One notice about your rights before you import
- Privacy settings list every connection Furiko makes, and updates are checked automatically
- Help menu: Send Feedback and Copy Diagnostics
